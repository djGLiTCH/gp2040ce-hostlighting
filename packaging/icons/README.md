# packaging/icons

The hlp icon: a leverless controller's buttons, each its own hue. The large
sizes show the whole layout, 48 and 32 pixels the eight action buttons, 24 and
16 pixels four buttons. `scripts/make_icons.py` draws every file here; draw them
again with it rather than editing them.

| File | What it does |
|---|---|
| `hlp.ico` | The Windows icon, 16 to 256 pixels, built into `hlp.exe` |
| `hlp.icns` | The macOS icon, 16 to 1024 pixels, in `hlp.app` |
| `hlp.png` | The 256-pixel icon the Linux desktop entry names |
| `hlp.svg` | The large icon as a drawing, shown at the top of the repository's README |
